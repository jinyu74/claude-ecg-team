# ADR: 아이디어 팀과 팀 설정 위치 통일

- 상태: **Accepted**
- 일자: 2026-10-02
- 의사결정자: 사용자
- 작성: Claude Code 세션 (사용자와의 대화로 확정한 내용을 기록)
- 선행: `2026-10-02-org-edu-game.md`, `2026-10-02-narrative-team.md`

## 1. 맥락

- 팀 설정이 루트(`members.conf`)와 `teams/` 로 나뉘어 일관성이 없었다.
- "무엇을 만들지"를 정하기 전에 프로젝트 팀(14~15명)을 먼저 띄우는 순서였다. 팀 구성 자체를 근거 없이 정하게 되고 비용도 크다.

## 2. 결정

1. **팀 설정은 모두 `teams/*.conf`.** `members.conf` → `teams/edu-game.conf`. 형식·배정 원칙은 `teams/README.md` 한 곳에 둔다.
2. `setup-team -c` 는 팀 이름(`-c edu-game` → `teams/edu-game.conf`)이나 경로를 받는다. **기본값은 아이디어 팀**.
3. **아이디어 팀** (`teams/idea.conf`, 10명, Claude 5 : Codex 5 — 사용자 요청으로 비율을 맞춤)
   - 진행 제임스, 컨셉 결정 페어 미야모토·라이트, 교육 관점 비고츠키·블룸, 서사 관점 닥터·드럭만, 조사 수진(Codex), 규모 추정 네이선(Codex), 비주얼 컨셉 수영
   - 진행: 주제 정의 → 독립 발산 → 관점별 검증 → 컨셉 결정 요청(사용자 결정: 컨셉·프로젝트 유형) → 팀 구성안(사용자 결정: 팀 구성) → 인계 (공통 §14)
4. **Codex 실행 옵션**: `--search`(웹 검색 — Codex 조사 역할에 필요), `-c check_for_update_on_startup=false`.

## 3. 사고 기록과 4번 결정의 근거

- 2026-10-02 `--search` 동작 확인 중, Codex 기동 시 업데이트 안내가 떠 있는 상태에서 테스트 입력의 Enter 가 "Update now" 로 선택되어 **Codex CLI 가 전역 npm 으로 0.159.3 → 0.160.0 업데이트**되었다(의도하지 않은 변경).
- 팀 자동 기동은 페인에 키 입력을 보내므로 같은 일이 반복될 수 있다. 기동 시 업데이트 확인을 꺼서 차단하고, 업데이트는 사용자가 직접 한다.

## 4. 결과·리스크

| 항목 | 내용 |
|---|---|
| 기존 세션 | 이전 경로(`members.conf`)를 기록한 세션은 `team-send` 가 설정을 찾지 못한다 — 다시 띄운다 (적용 시점에 실행 중인 세션 없음) |
| Codex 한도 | 아이디어 팀 Codex 5명은 모두 effort medium 으로 시작. 프로젝트 팀과 동시 실행 시 한도 공유 |
| 역할 파일 | 별도 아이디어 단계 역할 파일 없이 공통 §14 가 관점별 행동을 정한다. 운영해 보고 부족하면 보강 |

## 5. 재평가 시점

- 첫 아이디어 주제를 끝까지(팀 구성안까지) 진행한 뒤 — 발산 개수·검증 항목·Codex 한도 소모를 보고 조정한다.
